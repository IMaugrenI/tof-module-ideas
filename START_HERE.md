## How to read a candidate

A module entry is a **proposal**, not a release promise.

It may describe a problem, possible responsibilities, boundaries, likely system position, open questions, dependencies, and risks.

It does not mean the module exists in production or has been accepted for implementation.

## If you want to add a candidate

Use [docs/02_module_template.md](docs/02_module_template.md) and keep uncertainty explicit.

Do not add secrets, production IDs, internal hostnames, private service maps, or claims that an idea is already runtime truth.

For the broader architecture context, start with [tof-showcase](https://github.com/IMaugrenI/tof-showcase).
